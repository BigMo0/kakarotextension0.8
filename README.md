# Kakarot Extension

## 🚀 Installation

1. Open Paperback
2. Add this repository using [this link](paperback://addRepo?displayName=Kakarot%20Extension%200.8&url=https%3A%2F%2Fbigmo0.github.io%2Fkakarotextension0.8%2F)
3. Install and enjoy reading!
